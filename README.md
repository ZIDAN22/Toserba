# ToserbaZ - Mini E-Commerce

ToserbaZ adalah aplikasi web sederhana yang menampilkan daftar produk seperti toko serba ada (e-commerce) dengan fitur filter kategori, tampilan modern, dan navbar.

## Fitur
- Daftar produk dengan gambar, nama, deskripsi, dan harga
- Filter produk berdasarkan kategori (Elektronik, Fashion, Makanan, Minuman)
- Navbar modern dan footer
- Responsive design (CSS modern)
- Gambar produk menggunakan URL dari Unsplash (bisa diganti sesuai kebutuhan)

## Struktur Folder
```
Toserba/
├── index.html    # Halaman utama e-commerce
├── style.css     # Style khusus halaman e-commerce
└── script.js     # Script JS produk & filter
```

## Cara Menjalankan
1. Buka file `Toserba/index.html` di browser.
2. Pastikan koneksi internet aktif untuk menampilkan gambar produk dari Unsplash.
3. Gunakan dropdown filter untuk melihat produk berdasarkan kategori.

## Kustomisasi
- Untuk menambah produk, edit array `produk` di `script.js`.
- Untuk mengganti gambar, ubah properti `gambar` pada masing-masing produk.
- Untuk mengubah tampilan, edit file `style.css` sesuai kebutuhan.
